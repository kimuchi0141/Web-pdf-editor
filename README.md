# Web PDF Editor & Viewer

React 18、PDF.js、および pdf-lib をベースにした、高機能かつ軽量なブラウザ完結型 PDF ビューア＆アノテーション編集アプリケーションです。

ローカル環境やサーバーサイドへのデータ送信を一切行わず、ブラウザ内のみで高速かつセキュアにPDFの閲覧・注釈追加・しおり管理・変更後の高解像度保存・印刷が完結します。

## 🌟 主な機能

### 1. 自由なPDF読み込み & 閲覧操作
- **多彩なファイル読み込み**:
  - 右上ツールバーの「**ファイルを開く**」ボタン
  - キーボードショートカット (`Ctrl+O` / `Cmd+O`)
  - ウィンドウ全体へのPDFファイルの**ドラッグ＆ドロップ**（全画面ドロップオーバーレイ表示）
- **完全なドキュメント状態リセット**:
  - 新しいPDFを開いた際、既存の注釈・ハイライト・しおり・ページ位置・履歴を安全に自動リセット。
- **PDF.js 公式エンジン連携**: 高速・高精細なページレンダリング（拡大縮小・見開き・ページ回転対応）。
- **完全日本語ローカライズ**: ツールバーやサイドバー、検索、プロパティ情報を完全日本語化。

### 2. 多彩な注釈・編集（アノテーション）機能
- **💬 テキストボックス挿入 & 高度な入力制御**:
  - ツールバーボタンからの追加、または画面ダブルクリックによる任意座標への配置。
  - ドラッグ＆ドロップによる位置移動、ダブルクリックによるインライン再編集。
  - フォントサイズ（12px〜40px）および文字色（4色）のリアルタイム変更。
  - **日本語IME・確定処理の最適化**: 変換確定のEnterとテキスト完了Enterの自動判別、Spaceキーによるビューア誤スクロール防止、入力欄外クリック（blur）や「✓ 完了」ボタンでの即座の確実な確定反映。
- **✏️ 手書きペン**:
  - 線の太さ（1px〜18px）およびカラー（青・赤・黒・緑・橙・紫）の自由描画。
- **🖍️ フリーハンドハイライト**:
  - 蛍光マーカー風の半透明ハイライト下線・マーキング（4色、10px〜32px）。
- **📑 テキスト選択ハイライト**:
  - PDF文書内のテキストをマウスで選択するとポップアップが表示され、ワンクリックで4色（黄・緑・青・桃）のマーカーを付与。
- **🧹 消しゴムツール**:
  - クリックまたはドラッグで、近接するペン線・ハイライト・テキスト注釈を直感的に消去。

### 3. スマートなしおり（Bookmark）管理機能
- **カスタムしおりの追加**: 現在開いているページに対して、ワンクリックで自由にしおりを追加可能。
- **スムーズなページジャンプ**: しおり一覧をクリックすることで、該当ページへ自動スクロール。個別のしおり削除にも対応。
- **クリーンなUI表示**: しおりが1件以上登録されている場合、空状態メッセージ（「しおりはありません」）を自動的に非表示化。
- **文書本来のしおりの統合**: PDFファイル自身に含まれているアウトライン/目次情報も同時にサイドバー下部に表示。

### 4. 作業保護（誤リロード・離脱防止機能）
- **未保存警告（Unload Guard）**:
  - 注釈の追加・変更・削除やしおりの編集など、未保存の変更がある状態でブラウザをリロードしたりタブを閉じようとした場合、ブラウザ標準の離脱確認ダイアログを表示して作業内容の喪失を防止。

### 5. 変更後の高解像度PDF保存 & ダウンロード
- **完全クライアントサイド埋め込みエクスポート**:
  - `pdf-lib` を使用し、手書き線・ハイライト・テキスト・しおりをPDFバイナリ構造に直接埋め込み。
- **高い互換性と高精細出力**:
  - 印刷や外部ソフト（Adobe Acrobat、Chrome等）で開いても文字化けや画質劣化が一切生じません。

### 6. ネイティブ印刷プレビュー
- **注釈反映済みの印刷**:
  - 通常のPDF.js印刷では反映されない書き込み・テキスト内容を、独自バックエンド処理により変更後PDFとして瞬時に合成。
- **ブラウザネイティブ印刷ダイアログ**:
  - ブラウザ本来の印刷機能を呼び出し、A4用紙やプリンター設定に合わせて正確に印刷可能。

## ⌨️ キーボードショートカット

| ショートカット | 機能 |
| :--- | :--- |
| `Ctrl + O` / `Cmd + O` | PDFファイルを開く（ファイル選択ダイアログ） |
| `Ctrl + P` / `Cmd + P` | 印刷プレビュー（注釈反映済み印刷） |
| `Enter` | テキストボックス入力の完了・確定 |
| `Escape` | テキストボックス編集の終了 |
| `Delete` / `Backspace` | 選択中のテキストボックス・注釈を削除 |
| `Ctrl + スクロール` | 画面の拡大・縮小 |

## 🚀 クイックスタート

### 前提条件
- **Node.js**: v18.0.0 以上
- **npm**: v9.0.0 以上

### インストールと起動

```bash
# リポジトリのクローン
git clone https://github.com/kimuchi0141/Web-pdf-editor.git
cd Web-pdf-editor

# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173/)
npm run dev

# プロダクションビルド
npm run build

# ビルド成果物のプレビュー
npm run preview
```

## ⚙️ 堅牢性とパフォーマンスへの取り組み

本プロジェクトは、長時間利用や大規模PDFの取り扱いにも耐えうる設計を行っています：

1. **完全クライアントサイド・ゼロサーバー送信**:
   - 読み込んだPDFデータや編集内容は一切サーバーに送信されません。機密文書や個人情報を含む書類も安心して編集できます。
2. **徹底したメモリリーク防止**:
   - 動的に生成される `Blob URL` は、コンポーネントのアンマウント時やPDFファイル切り替え時に `URL.revokeObjectURL()` で確実に解放。
   - ドラッグ操作やキーボード監視イベントリスナーをライフサイクルに応じて確実にクリーンアップ。
3. **React Hooks の厳格な設計**:
   - `@react-pdf-viewer` の内部フック仕様に準拠し、レンダリングごとのフックキュー破損（`Should have a queue`）を防止。
   - コールバック内で最新値を参照するための `useRef` パターンを採用し、不要なコンポーネント再マウントを抑制。
4. **複数編集操作の整合性保証**:
   - 連番インクリメンタルカウンターによるユニークID生成で、高速編集時の注釈ID重複を防止。
   - テキスト入力の確定処理をステートマシン化し、入力確定とイベント発火の競合を解消。
