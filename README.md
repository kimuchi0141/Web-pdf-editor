# Web PDF Editor & Viewer

React 18、PDF.js、および pdf-lib をベースにした、高機能かつ軽量なブラウザ完結型 PDF ビューア＆アノテーション編集アプリケーションです。

ローカル環境やサーバーサイドへのデータ送信を行わず、ブラウザ内のみで高速かつセキュアにPDFの閲覧・注釈追加・しおり管理・変更後の高解像度保存・印刷が完結します。

---

## 🌟 主な機能

### 1. 高度なPDF閲覧 & 操作
- **PDF.js 公式エンジン連携**: `@react-pdf-viewer` をベースにした高速・高精細なレンダリング。
- **完全日本語ローカライズ**: ツールバーやサイドバー、ショートカット案内を完全日本語化。
- **サムネイル & ページ移動**: サムネイル一覧からの直感的なジャンプ、ページスクロール対応。
- **ドラッグ＆ドロップ対応**: ローカルのPDFファイルを画面上にドラッグ＆ドロップするだけで即座に開いて編集可能。
- **キーボードショートカット**: 印刷（Ctrl+P / Cmd+P）、拡大縮小、ページ遷移などのショートカットキーをサポート。

### 2. 多彩な注釈・編集（アノテーション）機能
- **✏️ 手書きペン**: 
  - 線の太さ（1px〜18px）およびカラー（青・赤・黒・緑・橙・紫）の柔軟なカスタマイズ。
- **🖍️ フリーハンドハイライト**: 
  - 半透明マーカーによるフリーハンド下線・マーキング（4色対応）。
- **💬 テキストボックス挿入**: 
  - ツールバーからのワンクリック追加、または画面ダブルクリックによる任意位置への追加。
  - テキストのフォントサイズ（12pt〜40pt）や文字色のリアルタイム変更。
  - ドラッグ＆ドロップによる位置移動、インライン編集対応。
- **📑 テキスト選択ハイライト**: 
  - PDF文書内のテキストをマウスで選択するとポップアップが表示され、ワンクリックで4色（黄・緑・青・桃）のマーカーを付与。
- **🧹 消しゴムツール**: 
  - クリックまたはドラッグで、近接するペン線・ハイライト・テキストを判定してスムーズに消去。

### 3. しおり（Bookmark）管理機能
- **カスタムしおりの追加**: 現在開いているページに対して、タイトルを指定して自由にしおりを追加可能。
- **ページジャンプ**: しおり一覧をクリックすることで、該当ページへスムーズに自動スクロール。
- **文書本来のしおりの統合**: PDFファイル自身に含まれているアウトライン/目次情報も同時にサイドバー下部に表示。

### 4. 変更後の高解像度PDF保存 & ダウンロード
- **完全埋め込みエクスポート**: `pdf-lib` を使用し、手書き線・ハイライト・テキスト・しおりをPDFバイナリ構造に直接埋め込み。
- **劣化のない高精細出力**: 300dpi相当のベクター/ラスター処理により、印刷や他ソフト（Adobe Acrobat等）で開いても文字化けや画質劣化が一切生じません。

### 5. ネイティブ印刷プレビュー
- **注釈反映済みの印刷**: 通常のPDF.js印刷では反映されない書き込み・テキスト内容を、独自バックエンド処理により変更後PDFとして瞬時に合成。
- **ブラウザネイティブ印刷ダイアログ**: ブラウザ本来の印刷機能を呼び出し、A4用紙やプリンター設定に合わせて正確に印刷可能。

## 🚀 クイックスタート

### 前提条件
- **Node.js**: v18.0.0 以上
- **npm**: v9.0.0 以上

### インストールと起動

```bash
# リポジトリのクローン
git clone https://github.com/<your-username>/web-pdf-editor.git
cd web-pdf-editor

# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:5173/)
npm run dev

# プロダクションビルド
npm run build

# ビルド成果物のプレビュー
npm run preview
```

## ⚙️ 堅牢性とパフォーマンスへの取り組み

本プロジェクトは、長時間利用や大規模PDFの取り扱いにも耐えうる設計を行っています：

1. **メモリリークの完全防止**:
   - 動的に生成される `Blob URL` は、コンポーネントのアンマウント時やファイル更新時に `URL.revokeObjectURL()` で確実に解放。
   - イベントリスナー（ドラッグ操作、グローバルキーボード監視）の参照管理とクリーンアップ。
2. **React Hooks の厳格な設計**:
   - `@react-pdf-viewer` の内部フック仕様に準拠し、レンダリングごとのフックキュー破損（`Should have a queue`）を防止。
   - コールバック内で最新値を参照するための `useRef` パターンを採用し、不要なコンポーネントの再マウントを抑制。
3. **描画負荷・メインスレッドの最適化**:
   - サンプルPDF生成・Canvasラスタライズ処理における過剰な解像度スケールを最適化し、初期メモリフットプリントを大幅に削減。
4. **複数編集操作の整合性保証**:
   - 連番インクリメンタルカウンターによるユニークID生成で、高速編集時の注釈ID重複を防止。
   - テキスト入力の確定処理を1箇所に集約し、フォーカス外れ時の二重コミット競合を解消。
